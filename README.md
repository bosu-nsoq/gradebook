## ✨ จุดเด่นและฟังก์ชันการใช้งาน

1. **ใช้งานง่ายบนมือถือแนวตั้ง (Portrait Optimized)**
   - ออกแบบการ์ดแก้วพรีเมียม (Glassmorphism) สบายตา ด้วยธีมสี Gradient ฟ้าพาสเทลและม่วงสดใส
   - แถบหัวเรื่องแสดงผลในบรรทัดเดียว (`white-space: nowrap`) เหมาะสำหรับหน้าจอมือถือ ไม่ตัดขึ้นบรรทัดใหม่
   - ตัวเลขขนาดใหญ่ พิมพ์ง่าย รองรับแป้นพิมพ์ตัวเลข (Numeric Pad) บนสมาร์ตโฟน

2. **ระบบความปลอดภัยด้วยรหัส PIN (PIN Lock System)**
   - ล็อคหน้าจอด้วยรหัส PIN 4 หลัก ป้องกันการแก้ไขคะแนนโดยไม่ได้รับอนุญาต
   - **รหัส PIN เริ่มต้น:** `8055`
   - แป้นพิมพ์ปุ่มกดตัวเลขสวยงาม รองรับทั้งการสัมผัสและการกดแป้นพิมพ์จริง (Numpad)
   - สามารถเปลี่ยนรหัส PIN ใหม่ได้ทันทีผ่านปุ่มรูปเฟือง (⚙️)

3. **แสดงข้อมูลเป็นปัจจุบันและสถานะการทำงานราบรื่น (Smooth Sync & Feedback)**
   - **Loading Overlay:** มีหน้าต่างโหลดพร้อมข้อความบอกสถานะเมื่อดึงข้อมูล เปลี่ยนห้องเรียน หรือสร้างห้องใหม่
   - **Auto Save & Toast Indicator:** แจ้งเตือนสถานะการบันทึกคะแนนแบบทันท่วงที (กำลังบันทึก / บันทึกสำเร็จ)
   - **ปุ่มรีเฟรชข้อมูล (🔄):** กดเพื่อซิงค์ข้อมูลล่าสุดจาก Google Sheets ได้ตลอดเวลา

4. **คำนวณและสรุปคะแนนอัตโนมัติ**
   - คำนวณคะแนนรวมสะสมและคะแนนเต็มแบบเรียลไทม์
   - ไฮไลต์คะแนนต่ำกว่าเกณฑ์ครึ่งหนึ่งด้วยสีส้ม-แดงเพื่อสังเกตได้ง่าย
   - กดปุ่ม `Enter` เพื่อเลื่อนเคอร์เซอร์ไปยังช่องคะแนนถัดไปโดยอัตโนมัติ

5. **ระบบจัดการห้องเรียนและช่องคะแนน**
   - ดึงรายชื่อห้องเรียนอัตโนมัติจากแท็บ Sheet ใน Google Spreadsheet
   - สามารถกดเพิ่มช่องคะแนนใหม่ พร้อมกำหนดคะแนนเต็มได้ทันที
   - สามารถสร้างห้องเรียนใหม่ได้โดยตรงจากเมนูเลือกห้อง

6. **ติดตั้งเป็นแอปพลิเคชันได้ทันที (Progressive Web App - PWA)**
   - รองรับการติดตั้งลงบนหน้าจอโฮมทั้ง iOS (iPhone/iPad) และ Android
   - ใช้งานแบบเต็มหน้าจอ (Standalone Fullscreen) เสมือนแอปพลิเคชัน Native โดยไม่มีค่าธรรมเนียม App Store

```text
gradebook/
├── index.html        # หน้าบ้าน (UI + UX + PIN System + PWA + Dual GAS Bridge)
├── Code.gs           # หลังบ้าน Google Apps Script (รองรับทั้ง Web App และ API Mode)
├── manifest.json     # การตั้งค่าเว็บแอปพลิเคชัน PWA
├── sw.js             # Service Worker สำหรับการแคชและการทำงานออฟไลน์
└── README.md         # เอกสารแนะนำและคู่มือการใช้งาน
```

## 🚀 คู่มือการติดตั้งและใช้งาน

### 1. การติดตั้งบน Google Apps Script (Backend)

1. เปิด [Google Sheets](https://sheets.new) และตั้งชื่อไฟล์ตามต้องการ (เช่น `Gradebook ครูบอส`)
2. ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. คัดลอกโค้ดจากไฟล์ `Code.gs` วางลงในไฟล์สคริปต์
4. สร้างไฟล์ HTML ใหม่ชื่อ `index` (คลิกปุ่ม `+` > `HTML`) แล้วคัดลอกโค้ดจาก `index.html` ไปวาง
5. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - เลือกประเภท: **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. คลิก **ทำให้ใช้งานได้ (Deploy)** และคัดลอก URL ของเว็บแอปที่ได้

### 2. การใช้งานผ่าน GitHub Pages (Dual Mode)

ระบบมี **GAS Bridge Proxy** ในตัว ทำให้สามารถรันบน GitHub Pages ได้ทันที:
1. เปิดหน้าเว็บ GitHub Pages ของคุณ
2. ที่หน้าจอกรอก PIN ให้กดปุ่มรูปเฟือง (⚙️)
3. เลือกหัวข้อ **2. ตั้งค่า Google Apps Script Web App URL**
4. วาง URL เว็บแอปของ Google Apps Script ที่ได้จากข้อ 1 (ลงท้ายด้วย `/exec`) แล้วกดยืนยัน
5. ระบบจะเชื่อมต่อกับ Google Spreadsheet ของคุณโดยตรงแบบเรียลไทม์!

## 📱 วิธีติดตั้ง PWA บนมือถือ

- **iOS (Safari บน iPhone / iPad):**
  1. เปิดลิงก์หน้าเว็บผ่านเบราว์เซอร์ **Safari**
  2. แตะปุ่ม **แชร์ (Share)** (ไอคอนกล่องที่มีลูกศรชี้ขึ้น)
  3. เลื่อนลงแล้วเลือก **"เพิ่มไปยังหน้าจอโฮม" (Add to Home Screen)**
  4. ตั้งชื่อ "Gradebook" แล้วแตะ "เพิ่ม" (Add)

- **Android (Chrome):**
  1. เปิดลิงก์หน้าเว็บผ่านเบราว์เซอร์ **Google Chrome**
  2. แตะที่เมนู 3 จุด มุมขวาบน
  3. เลือก **"ติดตั้งแอป" (Install App)** หรือ **"เพิ่มลงในหน้าจอหลัก" (Add to Home screen)**
