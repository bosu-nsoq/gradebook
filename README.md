## ✨ จุดเด่นและฟังก์ชันการใช้งานใหม่ล่าสุด

1. **อัปเดตข้อมูลอัตโนมัติ ไม่ต้องมีปุ่มกด (Auto-sync & Instant Save)**
   - บันทึกคะแนนอัตโนมัติทันทีที่พิมพ์ตัวเลขคะแนนลงในช่อง (Auto-save)
   - ดึงข้อมูลห้องเรียนและคะแนนให้อัตโนมัติทันทีที่เลือกชั้นเรียน
   - ซิงค์ข้อมูลเบื้องหลังอัตโนมัติเมื่อเปิดแท็บหรือตามระยะเวลา โดยไม่ต้องกดปุ่มรีเฟรช

2. **ป๊อปอัพโหลดน่ารักๆ (Cute Animated Loading Popup)**
   - แสดงป๊อปอัพแอนิเมชันดินสอดุ๊กดิ๊กพร้อมประกายดาววิบวับ ✨ ขณะกำลังบันทึกคะแนน, เพิ่มนักเรียน หรือสร้างช่องคะแนน
   - ข้อความภาษาไทยเป็นกันเอง เข้ากับฟอนต์น่ารัก 'Mali'
   - หายไปเองอย่างนุ่มนวลเมื่อดำเนินการสำเร็จ

3. **แยกช่องเก็บคะแนนของผู้ใช้แต่ละคนอย่างเด็ดขาด (User-Isolated Scoring)**
   - ครูแต่ละคนจะเห็นและบันทึกคะแนนได้เฉพาะในรายวิชาและบัญชีของตนเองเท่านั้น
   - คะแนนของครูแต่ละท่านจะไม่ปะปนหรือนำมาแสดงเหมือนกัน
   - **การจัดเก็บใน Google Sheets:** ตั้งชื่อชีตคะแนนตามรูปแบบ `[ชั้นเรียน]_[UserID]` (เช่น `ป.5/1_ADM01`, `ป.5/1_TCH01`)

4. **ฐานข้อมูลนักเรียนส่วนกลางใน Google Sheets (ชีต `Students`)**
   - ชีต **`Students`** มีโครงสร้างคอลัมน์มาตรฐาน: **`เลขที่`**, **`ชื่อ`**, **`ชั้น`**
   - ระบบดึงรายชื่อชั้นเรียนทั้งหมด (เช่น `ป.5/1`, `ป.5/2`, `ป.6/1`) มาให้ครูกดเลือกเพื่อบันทึกคะแนนได้ทันที
   - นักเรียนในชั้นเดียวกันจะปรากฏในสมุดคะแนนของครูทุกคนที่สอนชั้นนั้น

5. **ระบบการพิมพ์คะแนนเป็นห้องเรียน (Official Classroom Score Sheet)**
   - ออกแบบเอกสารรายงานผลคะแนนตามมาตรฐานราชการ โดยใช้ฟอนต์ **Sarabun (สารบรรณ) 100%**
   - แสดงข้อมูลรายวิชา, ชั้นเรียน, ครูผู้สอน และวันที่พิมพ์ในรูปแบบปี พ.ศ. (`dd/mm/yyyy พ.ศ.`)
   - คำนวณคะแนนรวม, ร้อยละ และผลการประเมิน (ผ่าน/ปรับปรุง) อัตโนมัติ พร้อมช่องลงนาม

6. **ระบบสิทธิ์สองระดับ (Admin & User Mode)**
   - **Admin (PIN: `8055`):** จัดการผู้ใช้ (เพิ่ม/แก้ไข/ลบ, กำหนดรหัส PIN), สร้างห้องเรียนใหม่
   - **User (PIN: `1234`):** บันทึกคะแนน, เพิ่มนักเรียนใหม่, เพิ่มช่องคะแนน, พิมพ์รายงาน

## 🔑 บัญชีและรหัส PIN สำหรับทดสอบ

| User ID | ชื่อ - สกุล | รายวิชา | รหัส PIN | สิทธิ์ (Role) | การเข้าถึง |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **ADM01** | ครูบอส | ภาษาไทย | **`8055`** | **Admin** | ทุกฟังก์ชัน + จัดการผู้ใช้ + สร้างห้องเรียน + บันทึกวิชาภาษาไทย |
| **TCH01** | ครูสมหมาย มีสุข | คณิตศาสตร์ | **`1234`** | **User** | บันทึกวิชาคณิตศาสตร์ + เพิ่มนักเรียน + เพิ่มช่องคะแนน + พิมพ์รายงาน |

## 📁 โครงสร้างโปรเจกต์

```text
gradebook/
├── index.html        # หน้าบ้าน (UI + UX + Cute Popup + Auto-sync + User Isolation + PWA)
├── Code.gs           # หลังบ้าน Apps Script (Students sheet, User-isolated score sheets, API Mode)
├── manifest.json     # การตั้งค่า Progressive Web App (PWA)
├── sw.js             # Service Worker สำหรับการแคชและการทำงานออฟไลน์
├── .nojekyll         # ปิด Jekyll บน GitHub Pages
└── README.md         # เอกสารแนะนำและคู่มือการใช้งาน
```
