## ✨ จุดเด่นและฟังก์ชันการใช้งานใหม่

1. **ดึงข้อมูลจาก Google Sheets และซ่อนการทำงานไว้เบื้องหลัง (Background Sync & Feedback)**
   - บันทึกคะแนนและดึงข้อมูลแบบซ่อนเบื้องหลัง ไม่บล็อกหน้าจอแบบกะทันหัน
   - มีป้ายแจ้งเตือนสถานะทันสมัย (**Status Toast**) ที่มุมบน เพื่อให้ผู้ใช้งานทราบสถานะการบันทึกข้อมูลอย่างราบรื่น
   - มีปุ่มรีเฟรชข้อมูล (🔄) ที่สามารถกดอัปเดตข้อมูลให้เป็นปัจจุบันได้ทันที

2. **ระบบการพิมพ์คะแนนเป็นห้องเรียน (Official Classroom Score Sheet)**
   - ออกแบบเอกสารรายงานผลคะแนนตามมาตรฐานราชการ โดยใช้ฟอนต์ **Sarabun (สารบรรณ) 100%** สำหรับพิมพ์
   - แสดงข้อมูลรายวิชา, ชั้นเรียน, ชื่อครูผู้สอน และวันที่พิมพ์ในรูปแบบปี พ.ศ. (`dd/mm/yyyy พ.ศ.`)
   - คำนวณคะแนนรวม, ร้อยละ และผลการประเมิน (ผ่าน/ปรับปรุง) อัตโนมัติ พร้อมช่องลงนามครูผู้สอนและหัวหน้าฝ่ายวิชาการ/นายทะเบียน

3. **โหมดผู้ดูแลระบบ (Admin Mode)**
   - เข้าใช้งานด้วยรหัส PIN ของ Admin (ค่าเริ่มต้น: `8055`)
   - **จัดการผู้ใช้:** เพิ่ม, แก้ไข, ลบข้อมูลผู้ใช้ กำหนดรหัสประจำตัว, ชื่อ-สกุล, รายวิชา, PIN 4 หลัก และกำหนดสิทธิ์การใช้งาน
   - **จัดการห้องเรียน:** สร้างห้องเรียนใหม่ (เพิ่มแท็บ Sheet อัตโนมัติ)
   - เข้าถึงฟังก์ชันการเพิ่มนักเรียน, เพิ่มช่องคะแนน, บันทึกคะแนน และพิมพ์รายงานได้ทั้งหมด

4. **โหมดผู้ใช้งาน (User Mode - ครูผู้สอน)**
   - เข้าใช้งานด้วยรหัส PIN ประจำตัวของตนเองที่ Admin กำหนดไว้ในตาราง
   - หัวข้อแอปจะเปลี่ยนเป็นวิชาและชื่อของครูผู้สอนที่เข้าสู่ระบบโดยอัตโนมัติ
   - **สิทธิ์การทำงานที่ได้รับอนุญาต:**
     - บันทึกและแก้ไขคะแนนนักเรียนในห้องเรียน
     - **➕ เพิ่มนักเรียนใหม่:** ระบุเลขที่ และชื่อ-สกุล นักเรียนเข้าสู่ห้องเรียนได้ทันที
     - **➕ เพิ่มช่องคะแนน:** กำหนดชื่อช่องคะแนนและคะแนนเต็มได้เอง
     - **🖨️ พิมพ์คะแนนห้องเรียน:** สั่งพิมพ์เอกสารรายงานผลคะแนนของห้องเรียนที่เลือก

5. **โครงสร้างฐานข้อมูลใน Google Sheets**
   - **ชีต `Users`:** จัดเก็บข้อมูลผู้ใช้งานทุกคน ได้แก่ `UserID`, `Name`, `Subject`, `PIN`, `Role` (admin/user) และ `CreatedAt`
   - **ชีตห้องเรียน (เช่น `ป.5/1`, `ป.5/2`):** แถวที่ 1 เป็นหัวคะแนน (No, Name, หัวข้อคะแนน), แถวที่ 2 เป็นต้นไปเป็นรายชื่อนักเรียนและคะแนน

## 📁 โครงสร้างโปรเจกต์

```text
gradebook/
├── index.html        # หน้าบ้าน (UI + UX + PIN System + Admin/User Mode + Print System + PWA)
├── Code.gs           # หลังบ้าน Google Apps Script (Users CRUD, Student CRUD, Scores, API Mode)
├── manifest.json     # การตั้งค่า Progressive Web App (PWA)
├── sw.js             # Service Worker สำหรับการแคชและการทำงานออฟไลน์
├── .nojekyll         # ปิด Jekyll บน GitHub Pages เพื่อให้โหลดไฟล์รวดเร็ว
└── README.md         # เอกสารแนะนำและคู่มือการใช้งาน
```

## 🚀 การติดตั้งบน Google Apps Script (Backend)

1. เปิด Google Spreadsheet ที่ต้องการใช้จัดเก็บข้อมูล
2. ไปที่ **ส่วนขยาย (Extensions) > Apps Script**
3. คัดลอกโค้ดจากไฟล์ `Code.gs` ไปวางในสคริปต์
4. สร้างไฟล์ HTML ชื่อ `index` แล้วนำโค้ดจาก `index.html` ไปวาง
5. กด **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
   - ประเภท: **เว็บแอป (Web app)**
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. นำ URL ที่ได้ (ลงท้ายด้วย `/exec`) ไปวางในหน้าเว็บ GitHub Pages ผ่านปุ่ม ⚙️ (ตั้งค่าระบบ) เพื่อเชื่อมต่อกับชีตจริง
